opencode + Gemini

Guida rapida — Lezione di IA

opencode è un assistente che programma con te, dentro il terminale. Per rispondere si collega a un modello di IA: useremo Google Gemini, che ha un piano gratuito. Ognuno usa la propria chiave: i limiti gratuiti valgono per chiave, quindi così non ci blocchiamo a vicenda.

1 Prendi la chiave (gratis)

  1. Apri aistudio.google.com/apikey
  2. Accedi con un account Google — non serve la carta.
  3. Premi Create API key.
  4. Copia la chiave e tienila da parte: è come una password.

2 Collega la chiave

Se l'installatore te l'ha già chiesto, sei a posto. Altrimenti apri Herdr (o il terminale di VS Code) dai collegamenti in Documenti\lezioni-AI:

$ opencode auth login --provider google
  • Se chiede il metodo, scegli API Key.
  • Incolla la chiave (tasto destro = incolla) e premi Invio.

3 Inizia a usarlo

Entra nella cartella progetti e avvia:

$ opencode
  • Con /models scegli un modello Gemini (es. flash).
  • Scrivi cosa vuoi fare e premi Invio.

4 Controlla l'accesso

Per vedere quali chiavi sono configurate:

$ opencode auth list

Deve comparire Google. Se non c'è, ripeti il Passo 2.

Se un modello è lento o dice “limite raggiunto”

Dentro opencode digita /models e passa a un altro modello Gemini gratuito. Di solito basta questo.

Oppure aggiungi un secondo provider gratuito come riserva (stessa procedura del Passo 2, cambia solo il nome):

  • OpenRouter — openrouter.ai/keys → opencode auth login --provider openrouter
  • Groq (velocissimo) — console.groq.com/keys → opencode auth login --provider groq
